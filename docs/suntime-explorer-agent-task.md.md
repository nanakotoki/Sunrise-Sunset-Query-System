# 全球日出日落时间查询网页 — Agent 开发任务书

## 一、项目概述

### 1.1 项目名称
**SunTime Explorer** — 全球日出日落时间查询器

### 1.2 项目目标
开发一个网页应用，用户可以输入经纬度（或地名），查看指定日期（年/月/日）下该地点的日出、日落、正午、昼长等太阳相关时间数据。

### 1.3 目标用户
- 摄影爱好者（黄金时刻规划）
- 户外/徒步/露营人群
- 天文爱好者
- 旅行规划者
- 普通好奇用户

### 1.4 核心价值
- 无需安装、纯网页即用
- 支持任意年份（含历史与未来）
- 支持任意经纬度（含极昼极夜特殊提示）
- 结果可视化、可导出

## 二、功能需求

### 2.1 必做功能（MVP）

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 经纬度输入 | 支持手动输入纬度(-90~90)、经度(-180~180)，含输入校验 |
| F2 | 日期选择 | 年、月、日三级选择，支持范围 1900–2100 |
| F3 | 日出/日落时间 | 显示该地当日日出、日落、太阳正午时刻 |
| F4 | 昼长计算 | 显示白昼总时长（时:分:秒） |
| F5 | 时区处理 | 默认按该经度估算时区；同时显示 UTC 时间 |
| F6 | 极昼/极夜提示 | 当太阳不升/不落时，给出明确提示而非报错 |
| F7 | 响应式布局 | 手机 / 平板 / 桌面均可用 |

### 2.2 增强功能（V1.1）

| 编号 | 功能 | 说明 |
|------|------|------|
| E1 | 地名搜索 | 输入城市名自动解析为经纬度（调用地理编码 API） |
| E2 | 地图选点 | 嵌入地图，点击地图拾取经纬度 |
| E3 | 全年视图 | 表格/折线图展示该地整年日出日落变化曲线 |
| E4 | 黄昏时刻 | 显示民用/航海/天文三种暮光时间 |
| E5 | 定位按钮 | 一键获取用户当前位置坐标 |
| E6 | 结果复制/导出 | 复制文本、导出 CSV |
| E7 | 多语言 | 中文 / 英文切换 |

### 2.3 非功能性需求
- 首屏加载 < 2s
- 计算在客户端完成（纯前端），无需后端服务器
- 无账号系统、无数据收集
- 兼容 Chrome / Firefox / Safari / Edge 最新两个大版本

## 三、技术方案

### 3.1 技术栈（推荐）
- **框架**：React + Vite + TypeScript（或原生 HTML/JS 亦可）
- **样式**：Tailwind CSS
- **天文计算库**：`suncalc`（轻量、成熟、纯 JS）
- **图表（可选）**：`recharts` 或 `chart.js`
- **地图（可选）**：`Leaflet`
- **地理编码（可选）**：Nominatim / OpenStreetMap（免费无 key）

### 3.2 核心算法说明
使用 SunCalc 库，关键调用：
